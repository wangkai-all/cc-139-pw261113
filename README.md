# 投资交易分析（investment-lotbook）

按账户查看持仓、已实现盈亏、现金流与总资产的分析工具。导入成交、费用、汇率与公司行动，
以 **FIFO（先进先出）** 计算批次成本；点开一笔卖出即可看到它消耗了哪些买入批次。
零外部依赖（Node.js 内置模块），随项目自带合成行情与交易样本，不连接任何实时证券接口。

## 快速开始

```bash
npm start        # 启动服务，默认 http://localhost:3000（PORT 环境变量可改）
npm test         # 运行引擎测试（node:test，13 项）
```

首次启动自动生成样本数据到 `data/`（v1 版本）。页面右上角「重置样本」可随时恢复。

## 计算规则（每项盈亏都能追到批次和换算依据）

| 规则 | 实现 |
|---|---|
| 成本方法 | 先进先出。买入形成批次（lot），单位成本 =（成交金额 + 关联费用）÷ 数量 |
| 费用分摊 | 关联成交的费用：买入计入该批次单位成本；卖出按各批次**消耗数量占比**分摊。不关联成交的独立费用（如账户管理费）只影响现金流，不进成本 |
| 部分卖出 | 只扣减被消耗数量，批次剩余数量与单位成本原样保留 |
| 拆股 | 除权日对全部未平仓批次：数量 × 比例、单位成本 ÷ 比例，成本总额不变 |
| 现金分红 | 除息日快照持仓，派息日按快照数量 × 每股分红计入现金，是**独立现金流**；行情用未复权收盘价，分红不再计入成本或盈亏，不会重复计算 |
| 多币种 | 每笔金额同时保存交易币与报告币口径；**已实现盈亏按成交日汇率**折算，**估值（市值/现金/总资产）按估值日汇率**折算，各自记录所用汇率与日期 |
| 汇率/行情取值 | 取当日或之前最近一条；取不到**不估算**，计入「数据缺口」单独展示，相应项目不计入总资产 |
| 仅现货多头 | 卖出数量超过持仓 → 记录错误并跳过该笔成交，绝不暗中按做空处理 |
| 计算版本 | 数据集按版本不可变快照（`data/vN.json`）；导入与冲正都生成新版本，可切换核对 |
| 冲正 | 原记录保留但标记「已冲正」不参与计算，可同时追加更正记录，生成新版本 |

日内事件顺序：入金 → 拆股 → 除息 → 成交 → 分红到账 → 独立费用。

## 核对演练（可手工复算）

1. **FIFO 与费用分摊**（成交与批次 → 点 t7）：
   批次 t1 消耗 100 股 @180.05，分摊费用 5×100/120=4.1667，盈亏 2990.83；
   批次 t4 消耗 20 股 @195.0833，分摊费用 0.8333，盈亏 297.50；合计 **3288.33 USD**，
   按成交日汇率 7.23 = **23774.65 CNY**。
2. **拆股前后**（总览 → 时间推进到 2024-08-31 与 2024-09-02）：AAPL 40 股 @195.0833 → 160 股 @48.7708，
   成本总额 7803.33 USD 不变，总资产不因拆股跳变（价格同日 220→55 是未复权市价）。
3. **卖出后**（2025-01-20，t10）：消耗拆后批次 100 股 @48.7708，盈亏 6000−2−4877.08=**1120.92 USD** × 7.33 = **8216.32 CNY**；现金增加、持仓市值下降，时间轴上逐步可见。
4. **冲正生成新版本**（数据与版本 → 演示冲正）：撤销 t10 并更正为卖出 80 股，生成 v2；
   在 v1/v2 间切换，已实现盈亏与总资产随之变化（v2 中该笔盈亏 896.33 USD）。
5. **缺价**：DEMO.US 持仓始终显示「缺价」，列在数据缺口面板，不计入总资产。

## API 一览

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/bootstrap` | 账户、标的、版本列表、最后日期 |
| GET | `/api/version/:n/dataset` | 某版本原始数据集 |
| GET | `/api/version/:n/compute?account=&asOf=` | 截至某日期的完整计算状态 |
| GET | `/api/version/:n/timeline?account=` | 逐日资产快照（时间推进/走势图） |
| GET | `/api/version/:n/trade?id=` | 单笔成交的批次消耗/剩余追溯 |
| POST | `/api/import` | 校验并导入记录，生成新版本 |
| POST | `/api/reverse` | 冲正记录（可带更正记录），生成新版本 |
| POST | `/api/reset` | 恢复样本数据 |

## 目录结构

```
server/engine.js       核心计算引擎（FIFO 批次、公司行动、多币种、估值、时间轴）
server/sample-data.js  自带样本：行情、汇率、成交、费用、公司行动、入金
server/store.js        版本化 JSON 存储（data/vN.json 不可变快照）
server/validate.js     导入校验与合并
server/server.js       零依赖 HTTP 服务（API + 静态文件）
public/                单页前端（总览 / 成交与批次 / 现金流与盈亏 / 数据与版本）
test/engine.test.js    引擎规则测试（13 项）
```
